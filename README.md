# HackerTube (unofficial Android app)

A minimalist, ad-free-by-design reader for [HackerTube](https://hackertube.org):
the YouTube videos Hacker News keeps telling each other to watch.

**Features**
- Home feed: Top rated / Recently discussed / Surprise me, filter by Talks, Explainers, Demos, Lectures…
- Local search (title, channel, topic, tags, summary) – works offline
- Browse 16 areas / 150 topics
- Video page: player, "why HN watches this", summary, best HN quote, HN comments, "more like this"
- Like, Watch later, History (all stored on-device only)
- **Paths:** 16 structured courses (topics in order, easiest first) with progress, "Continue", notes and export/import
- **Ask about this video:** offline answers from HackerTube summaries and HN comments; optional on-device AI model (off by default)
- Light / Dark / System theme, fullscreen player, share, open in YouTube
- No account, no analytics, hardened WebView (see SECURITY.md)

**Install:** download `HackerTube.apk` from the latest Release (or from the Actions run artifact),
allow "install unknown apps", open it. Android 8.0+.

**Build:** push to GitHub; the *Build APK* workflow produces the APK. Or open in Android Studio and press Run.

**Data:** `app/src/main/assets/` is a compacted snapshot (31 Oct 2026) of the HackerTube data export,
regenerated by `tools/preprocess.py`. See NOTICE.md for attribution.
